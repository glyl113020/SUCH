Lists & ratings

Every drop-down on the main site comes from these lists. Values that users add with (NEW) arrive as PENDING REVIEW. Fix a typo by editing the value and saving. If it matches another value, the two are merged and every record is moved over. Changing an OS rating re-scores every Software record that uses it. A value that is still used by records can only be deactivated, not deleted.

OS rating guide · 1 LOW — Current: latest supported release (e.g. Windows 11 24H2 / 25H2). 2 NORMAL — Outdated: still gets Microsoft security updates but is not the latest version. 3 HIGH — End of support: no more security updates (e.g. Windows 10, 8.1, 7, XP).

Expected system access per position

User score: no untrained systems = 1 · some untrained (less than half) = 2 · half or more untrained = 3. It goes up by 1 when the user has more systems than the position should have, and if any system has no training it is at least the minimum below (MANAGERIAL = 2).
